# Chief Developer Hub / Projektgedächtnis

Lauffähige Web-App mit Backend für GitHub-Repos, Projektgedächtnis, verschlüsselte Secrets, ChatGPT-Kontext, ZIP-Deploy und Rollback.

Start:

```bash
cp .env.example .env
nano .env
npm install
npm start
```

Dann im Browser öffnen:

```text
http://SERVER-IP:8787
```
