# Roadmap

## Version 1.0

Kern steht:

- GitHub-Repos laden
- Code scannen
- Projektgedächtnis speichern
- ChatGPT-Kontext erzeugen

## Version 1.1 ZIP-Deploy

Geplant:

- Repository auswählen
- ZIP hochladen
- ZIP im Browser entpacken
- enthaltene Dateien ins Repository schreiben
- nicht enthaltene Dateien behalten
- letzten Commit vor Upload merken
- Button: letzten Upload rückgängig machen

## Version 1.2 Firebase-Schutz

Geplant:

- Firebase-Projekte aus allen Repos erkennen
- gemeinsame Realtime Database sichtbar machen
- Rules separat anzeigen
- Warnung vor vollständigem Überschreiben
- Kontextgenerator nimmt Gesamtstand automatisch auf

## Version 1.3 VPS und Bots

Geplant:

- Serverdaten lokal oder verschlüsselt speichern
- Bots manuell Projekten zuordnen
- PM2, Docker, systemd dokumentieren
- Start-, Stop- und Restart-Befehle speichern
- Logs später anzeigen

## Version 1.4 Auto-Doku nach Upload

Geplant:

- nach ZIP-Upload automatisch neu scannen
- erkannte Änderungen anzeigen
- Projektgedächtnis aktualisieren
- keine Pflicht zur manuellen Beschreibung jeder Kleinigkeit

## Version 2.0 Entwicklerzentrale

Ziel:

- ein Ort für GitHub, Firebase, VPS, Bots und ChatGPT-Kontext
- Projektabhängigkeiten erkennen
- neue Chats ohne Kontextverlust starten
- einfache Handy-Nutzung
